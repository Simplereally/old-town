# Trail Collection Log

The Trail Collection Log tracks a player's lifetime Trail activity. It is a log, not a reward treadmill. It exists for completion, bragging rights, and cosmetic rewards.

## Log Categories

The log tracks these categories:

| Category | What is tracked |
|----------|-----------------|
| Trails completed by tier | Total Trails completed at each tier |
| Caches opened by tier | Total Caches opened at each tier |
| Rare rewards found | Unique rare cosmetics and items found |
| Nooks built | Total Nooks built and their locations |
| Trail enemies defeated | Total Trail ambush enemies defeated |
| Unique Trail steps completed | Total distinct step types completed |
| Starfall Trail completions | Total Starfall Trails completed |

## Log Display

The log is accessed through a book or journal item. It displays:

- Tier completion counts (Scrap, Chalk, Writ, Grave, Crown, Starfall)
- Total Caches opened
- Rare reward list with checkboxes
- Nook map showing built locations
- Enemy kill counts by type
- Step type completion counts
- Starfall completion count

## Log Rules

1. The log is permanent. It tracks lifetime activity.
2. Log rewards are cosmetic only. No stat bonuses, no power.
3. Log milestones are generous. They reward consistent play, not grinding.
4. Log pages are visible to other players. They are a bragging right.
5. Log progress is account-wide. Alts share the same log.
6. Log rewards are retroactive. If a player completes a milestone before the log exists, they receive the reward when the log is introduced.

## Future Integration

In future housing systems, the log may unlock:

- Display case for Trail rewards
- Trophy wall for Starfall completions
- Nook model for each built Nook
- Trail map wall showing completed areas

These are not power rewards. They are cosmetic housing items.
