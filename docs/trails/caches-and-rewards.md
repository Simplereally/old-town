# Caches and Rewards

Caches are the reward containers awarded at the completion of a Trail. Each tier has a matching Cache tier. Rewards are cosmetic-heavy, exciting, and not mandatory.

## Cache Tiers

| Trail | Cache | Identity |
|-------|-------|----------|
| Scrap Trail | Scrap Cache | Torn sack, cheap, rattles |
| Chalk Trail | Chalk Cache | Chalk-dusted box, faint bead smell |
| Writ Trail | Sealed Cache | Wax seal, legal weight, ribbon |
| Grave Trail | Grave Cache | Crypt soil, bone dust, moss |
| Crown Trail | Crown Cache | Gold leaf, perfumed, heavy |
| Starfall Trail | Starfall Cache | Silver thread, star watermark, no sound |

## Reward Categories

Caches can contain items from these categories:

| Category | Description | Example |
|----------|-------------|---------|
| Coins | Direct coin reward | 100-5000 coins |
| Materials | Raw or processed materials | Bead clay, iron ore, hide |
| Consumables | Food, potions, candles | Bellbread, shrine candle |
| Beads | Fired or unfired beads | Chalkmarked bead, grave bead |
| Trail Gear | Cosmetic items for Dress Steps | Ragged cape, chalk-dusted robe |
| Ornament Kits | Visual upgrades for gear | Bell trim, writ stamp |
| Emote Unlocks | New gestures or dances | Bellstruck emote, trail fool dance |
| Titles | Character titles | Scrapfoot, Writ-Chaser |
| Nook Materials | Materials for building Nooks | Planks, fittings, map scraps |
| Rare Cosmetics | Desirable visual items | Graveflower cape, starfall thread |
| Strange Utility | Odd, useful items | Map tube upgrade, large trowel |

## Reward Rules

1. Trail rewards should be exciting but not required.
2. Cosmetics are king. The most desirable rewards are visual.
3. Trimmed gear is good if narrow and visual. It should not be best-in-slot.
4. Rare utility should be odd, not universally powerful.
5. Low-tier Trails can have desirable cosmetics.
6. Starfall rewards should be rare and strange, not raw stat creep.
7. No reward should be mandatory for progression.
8. No reward should be tradeable for power.

## Reward Scaling

Reward value and rarity scale with tier:

- Scrap: small coins, basic materials, silly cosmetics.
- Chalk: moderate coins, bead materials, chalk cosmetics.
- Writ: good coins, permit fragments, writ-themed items.
- Grave: nice coins, grave beads, bone trophies, crypt keys.
- Crown: large coins, elegant cosmetics, rare ornaments, route hooks.
- Starfall: very large coins, master cosmetics, unique trophies, strange utility.

## Cache Opening

Caches are opened by right-clicking or using the item. The player sees a brief animation and the rewards are revealed. Caches can be opened anywhere. There is no special location requirement.

## Trade Rules

- Caches are untradeable. The Trail item can be traded, but the Cache cannot.
- This prevents market flooding and preserves the reward identity.
- A player who buys a Trail gets the Cache themselves upon completion.
