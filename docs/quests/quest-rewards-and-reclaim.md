# Quest Rewards and Reclaim

Quest rewards should teach loops instead of dumping power.

Coin rewards, reclaim fees, and unlock value should follow [`../economy/reward-calibration.md`](../economy/reward-calibration.md) and [`../economy/banks-storage-and-reclaim.md`](../economy/banks-storage-and-reclaim.md).

## Reward Rules

Use:

- Access to a station.
- Starter item.
- Recipe unlock.
- Shop stock unlock.
- Route unlock.
- Warden contract unlock.
- Favour boon unlock.
- Container upgrade.
- Cosmetic title.
- NPC service discount.
- Quest item reclaim.

Avoid:

- Large coin dumps.
- Best-in-slot equipment.
- Huge XP skips.
- Universal combat bonuses.

## Quest Item Rules

| Rule | Meaning |
|------|---------|
| Quest-prefixed IDs | Use `{quest_slug}_{item_descriptor}` |
| Usually untradeable | Quest items are story objects |
| Reclaimable | Important items can return through Tomas Tally or the giver |
| Flavourful destroy text | Destroy text should sound like Old Town |
| Examine text matters | Quest item examines carry clues and tone |
