# String Enough to Sing

Giver: **Letha Lath**

Primary systems: Woodcutting, Bowcraft, Trapping

Hook: "A bow that does not sing is just a bent stick with ambition."

## Items

- Lathwood Bow Stave.
- Sinew Cord.
- Bellfeathers.

## Beats

1. Letha Lath asks for a bow that can hold a note.
2. Player cuts Lathwood or Oldroad Oak.
3. Player gets Sinew Cord and Bellfeathers.
4. Player strings a Lathwood Shortbow and makes arrows.

## Rewards

- Lathwood Shortbow.
- Starter arrows.
- Bow Bench recipe unlock.
