# Starter Town

The starter town is **Old Town**.

Old Town is a compact hub-and-spoke town where the Market Bell anchors first arrival, the Counting House anchors safety, and each surrounding district teaches a skill loop through a named NPC, shop, station, and nearby resource or danger.

## First-Session Goals

| Goal | Town Anchor |
|------|-------------|
| Learn where to bank | Counting House |
| Learn first trading and rumours | Market Bell |
| Make Full Penny | Foundry Row |
| Make Full Lath | Lath Yard |
| Make Full Patch | Patch Lane |
| Make Full Chalk | Chalkhouse Court |
| Catch and cook food | River Stoop |
| Take first contract | Warden Steps |
| See Favour as a civic system | Shrine Hearth |
| Notice danger beyond comfort | Gravegate and Sootcellar |
| Start the Civic Ledger | Counting House (Tomas Tally) |

## Acceptance Rules

1. Every starter identity has a place, NPC, station, and loop.
2. Every starter production station has an initial location.
3. Shops have clear stock identities, not random inventories.
4. Starter monsters have local ecology and drops.
5. Quest hooks exist without expanding into full quests.
6. No decorative-only NPCs in the first pass.
