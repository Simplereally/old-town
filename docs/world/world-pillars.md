# World Pillars

Old Town is not a heroic staging ground first. It is a working town with old layers underneath it.

## Pillars

1. **A town built over older towns.** Cellars, sealed roads, undercrofts, old wells, grave stairs, bricked-up shrines.
2. **Trade before heroism.** Smiths, fishmongers, beadwives, wardens, tanners, ferrymen, cartographers.
3. **Magic as civic craft.** Beads, writs, chalk, seals, shrines, permits, counterfeit spellwork.
4. **Combat as local danger.** Rats, goblins, stray drakes, grave things, bandits, contracts.
5. **Every station has a person.** Anvils, kilns, benches, boards, shrines, and kitchens are social anchors.
6. **The town is the tutorial.** No popup-heavy tutorial island. The first loops happen naturally through streets and shops.

## Design Rules

1. Name people, shops, districts, and stations before adding generic services.
2. Keep early danger local and pathetic before it becomes mythic.
3. Every starter system should have a visible place in town.
4. Every starter NPC should own a system or loop.
5. The first 30 minutes should be playable on paper.
