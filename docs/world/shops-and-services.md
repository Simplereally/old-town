# Shops and Services

Starter shops teach identities. Stock lists should be small, legible, and tied to the NPC's loop.

## Services and Stock

| Place | NPC | Services | Starter Stock |
|-------|-----|----------|---------------|
| Counting House | Tomas Tally | Deposit, withdraw, reclaim, coin exchange | Basic storage access |
| General Stall | Mara Bellkeeper | Rumours, common junk buyback | Rope Belt, Threadbare Tool Roll, Bellbread, empty phials, basic tinder, blank maps, cheap needles, basic knives, starter bait |
| Penny and Sons Forge | Osric Penny | Smithing intro, starter repairs | Pennywrought Pickaxe, Pig Iron Hammer, tongs, moulds, Blackcoal bundles |
| Lath and Twine Bowyer | Letha Lath | Bowcraft intro | Whittling Knife, Sinew Cord, Bellfeathers, arrow shafts, Lathwood Shortbow, Lathwood Arrows |
| Patch and Awl | Nell Patch | Tanning service, tailoring intro | Bone Needle, Awl, Threadbare Belt, Patchhide Coif, Patchhide Jerkin, Patchhide Chaps, basic dyes |
| Chalkhouse | Mother Tallow | Beadwork and basic magic intro | Chalkmarked Wand, Chalkmarked Primer, basic beads, Threadbare Bead Pouch, Bead Drill, Glaze Bowl |
| Warden Board | Warden Holt | Rat contract, goblin contract, first bounty | Tin Badge, Warden Contract Book, simple contracts |
| Shrine Hearth | Sister Writ | Restore Favour, bless beads, cleanse poison or rot, accept offerings | Shrine Candle, Prayer Knot, Grave Flower |
| River Stoop | Edda Tinfin, Bramble Hook | Fishing tutorial, cooking tutorial, ferry later | Reed Rod, Small Net, Market Pot, Ditch Shrimp Skewer, Tinfin Pie |
| Sootcellar | Marn Lock | Lockpick tutorial, black market hints | Bent Pick, False-Bottom Pouch later, Blank Writ later |

## Early Economy Sinks

| Sink | Example |
|------|---------|
| Tool repair | Repair degraded tools |
| Station fees | Small fee for public furnace or kiln |
| Ferry fees | Later travel unlock |
| Bank container fee | Expanded storage tabs |
| Warden contract deposit | Higher contracts require a bond |
| Shrine offerings | Favour restore or blessing |
| Map copying | Cartography service |
| Tanning fee | Hide curing |
| Bead firing fee | Public kiln |
| Death reclaim | Counting House reclaim |

## Design Rules

1. Shops should sell missing loop glue, not finished best-in-slot gear.
2. Early sinks should be small and charming.
3. Services should explain why the NPC exists.
4. Reclaim and storage rules belong at the Counting House until a stronger system replaces it.
