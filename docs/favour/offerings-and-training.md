# Offerings and Training

Offerings are the item economy behind Favour. Rites decide how much risk, preparation, and XP the player gets.

## Offerings

| Offering | Source | Used For |
|----------|--------|----------|
| Small Bones | Rats, dogs, starter creatures | Starter Favour XP |
| Bone Chips | Grave Mites | Cheap grave rites |
| Ash | Hearthcraft, drakes, fires | Foundry/Hearth rites |
| Blackcoal Ash | Ash Drake Whelp, smithing | Stronger heat/forge rites |
| Grave Dust | Grave Mites | Grave boons, anti-rot |
| Grave Flower | Gardening / Gravegate | Shrine offerings, cleanse |
| Prayer Knot | Handicraft / Tailoring | Boon extension |
| Shrine Candle | Hearthcraft | Restore and rites |
| Votive Bead | Beadwork | Bead/magic/Favour crossover |
| Bell Token | Wardenry / shops | Civic shrine offering |
| Drake Tooth | Ash Drake Whelp | Warden/Favour contract proof |
| Saintbone | Rare trophy source | High-tier Argent offering |

## Training Methods

| Method | Description | XP Profile |
|--------|-------------|------------|
| Field Rite | Perform rite immediately on bones/ash in the field | Low XP, convenient |
| Shrine Offering | Bring offering to correct shrine | Normal XP |
| Prepared Offering | Combine offering with candle/knot/flower first | Higher XP |
| Contract Rite | Complete Warden contract and dedicate proof item | High XP, gated |
| Grave Rite | Use bones/dust/flowers at Gravegate Shrine | High XP, danger-adjacent |
| Festival Offering | Rare event/community offering | Social/economy sink |
