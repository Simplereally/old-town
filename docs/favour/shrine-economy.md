# Shrine Economy

Favour creates recurring demand without relying only on combat gear.

## Sinks

| Sink | Example |
|------|---------|
| Candle demand | Shrine Candles consumed constantly |
| Flower demand | Grave Flowers for crypt runs |
| Bone demand | Favour training |
| Bead demand | Votive Beads and blessed spellwork |
| Potion demand | Favour Cordials, Argent Wash |
| Service fees | Shrine restoration, cleansing |
| Wardenry | Contract proofs can be dedicated |
| Hearthcraft | Candles, ash, kiln rites |

## Design Rules

1. Shrine fees should stay small early.
2. Gravegate should consume flowers, bone chips, grave dust, and cleanse items.
3. Shrine Hearth should remain the starter restore anchor.
4. Warden contracts should feed Favour through proof dedication.
5. Apothecary and Hearthcraft should both gain reliable demand from Favour.
