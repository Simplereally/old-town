# Favour Items

These item families make Favour a material economy instead of a renamed point bar.

| Item | Skill Source | Purpose |
|------|--------------|---------|
| Shrine Candle | Hearthcraft | Basic rite input |
| Prayer Knot | Tailoring / Handicraft | Boon extension |
| Votive Bead | Beadwork | Bead/Favour crossover |
| Offering Bowl | Handicraft | Prepared offerings |
| Grave Flower | Gardening | Gravegate offerings |
| Bell Token | Wardenry / shops | Civic offering |
| Blessed Oil | Apothecary | Cleanse, blessing, weapon oil crossover |
| Argent Wash | Apothecary | Anti-curse / cleanse |
| Favour Cordial | Apothecary | Restore Favour points |
| Saintbone Fragment | Rare drops | High-tier Favour training |
| Writ Ribbon | Tailoring / Sleight | Warden/Writ rites |
| Ash Bundle | Hearthcraft | Foundry/Hearth offerings |

## Design Rules

1. Favour items should cross at least one other skill.
2. Starter Favour items should be cheap, visible, and teach shrines.
3. High-tier Favour items should be sink-heavy and culturally specific.
4. Favour Cordials restore points; offerings train XP.
