# Favour System

Favour is Old Town's combat support skill. It governs shrine boons, blessings, protections, oaths, cleansing, grave rites, and civic shrine standing.

## System Terms

| Concept | Old Town Term | Meaning |
|---------|---------------|---------|
| Prayer skill | Favour | Combat/support skill |
| Prayer points | Favour points | Spendable resource |
| Prayers | Boons | Toggleable or timed buffs |
| Altars | Shrines | Restore, bless, train, cleanse |
| Bones/offerings | Offerings | Items consumed for Favour XP |
| Ritual actions | Rites | Shrine interactions |
| Protection prayers | Wards | Defensive boons |
| Strong vows | Oaths | Higher-tier boons with restrictions |
| Prayer potions | Favour Cordials | Restore Favour points |
| Blessed items | Shrine-blessed | Temporary blessed utility state |

## Design Rules

1. Favour points are spent by boons and restored through shrine actions, items, or services.
2. Favour XP comes from rites, offerings, contract dedication, and shrine work.
3. Bones are one path, not the whole skill.
4. Candles, flowers, knots, ash, beads, writs, and proof items all matter.
5. Shrines are place-based. Do not use one generic altar model for every loop.
6. Oaths must have tradeoffs.
7. PvP-risky boons must be capped when implemented.

## Player Language

- "Bring grave flowers."
