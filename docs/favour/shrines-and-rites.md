# Shrines and Rites

Shrines are places. Rites are the actions players perform at them.

## Shrine Types

| Shrine | Location | Role |
|--------|----------|------|
| Shrine Hearth | Central Old Town | Starter restore, simple offerings, candles |
| Gravegate Shrine | Gravegate | Bones, Grave beads, anti-rot, crypt boons |
| Warden Shrine | Warden Steps | Contracts, Writ blessings, lawful protections |
| Road Shrine | Oldroad Gate | Wayfaring, travel, stamina, safe passage |
| River Shrine | River Stoop | Fishing luck, ferry safety, tide rites |
| Foundry Shrine | Foundry Row | Heat resistance, smithing luck, ash rites |
| Greenwold Shrine | Later forest edge | Hunting, trapping, foraging |
| Argent Shrine | Late-game | Cleanse, anti-curse, support boons |
| Starfall Shrine | Endgame | Rare, capped, prestige rites |

Starter town uses Shrine Hearth, Warden Shrine, and Gravegate Shrine early.

## Rites

| Rite | Shrine | Effect |
|------|--------|--------|
| Light Candle | Shrine Hearth | Restore small Favour, trains Hearthcraft/Favour |
| Offer Bones | Any shrine | Favour XP |
| Name the Dead | Gravegate Shrine | More XP from bones and dust |
| Bless Beads | Shrine Hearth / Chalkhouse | Improve bead crafting or spell prep |
| Cleanse Rot | Gravegate / Argent Shrine | Removes rot or curse status |
| Take Warden Oath | Warden Shrine | Enables contract boon |
| Road Blessing | Road Shrine | Short travel/stamina boon |
| Ash Rite | Foundry Shrine | Heat resistance / forge luck |
| Grave Flower Rite | Gravegate | Crypt sustain / undead resistance |
