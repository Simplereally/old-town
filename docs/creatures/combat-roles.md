# Combat Roles

Early creatures teach movement, targeting, weapon choice, food timing, and cleansing without becoming stat blobs.

| Role | Purpose | Example |
|------|---------|---------|
| Training Dummy | Safe first kill | Cellar Rat |
| Pursuer | Teaches movement and leashing | Stray Dog |
| Scrapper | Basic melee enemy | Mud Goblin |
| Flier | Weak to ranged or magic | Bell Bat |
| Skittish Beast | Flees, trapping crossover | Bog Fox |
| Rotter | Introduces poison, rot, cleanse | Grave Mite |
| Resistant Spirit | Teaches magic/Favour interaction | Grave Wisp |
| Armoured Small Boss | Teaches javelin, maul, armour break | Ash Drake Whelp |
| Rogue Humanoid | Teaches Sleight and anti-bandit contracts | Blacksealed Cutpurse |

## Design Rules

1. A new role should teach one thing clearly.
2. Weaknesses should make early weapon families matter.
3. Local danger comes before world-ending danger.
