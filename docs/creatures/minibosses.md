# Minibosses

Early minibosses are named local threats. They are not full bosses yet.

## The Cellar King

| Field | Value |
|-------|-------|
| Area | Sootcellar |
| Creature type | Huge rat |
| Teaches | Food timing, melee basics, Wardenry contracts |
| Drops | Ratcatcher Tail, torn cloth bundles, Bent Nail Ring |
| Weakness | Cudgel / Shortblade |
| Unlock | After Rats Under Tally's |

## Mudhook Grib

| Field | Value |
|-------|-------|
| Area | North quarry road |
| Creature type | Named Mud Goblin |
| Teaches | Armour, block, stagger, food |
| Drops | Pig Iron Scrap, Crude Cudgel, Mud Charm |
| Weakness | Maul / Javelin armour-break |
| Unlock | Warden contract |

## Ashling in the Kiln

| Field | Value |
|-------|-------|
| Area | Old kiln near Sootcellar / Foundry Row |
| Creature type | Ash Drake Whelp |
| Teaches | Heat damage, positioning, ranged/magic safety |
| Drops | Warm Scale, Tallow Drake Scale, Drake Tooth |
| Weakness | Tide Beads / ranged piercing |
| Unlock | Smoke Over Old Town hook |
