# Rare Drops and Trophies

A trophy should make a player say "oh, you did that content," not "that is best everywhere."

## Trophy Canon

| Trophy | Source | Effect Identity |
|--------|--------|-----------------|
| Ratcatcher Tail | Cellar Rat rare / contract | Starter Wardenry proof |
| Bell Boar Tusk | Later beast | Stagger / cudgel support |
| Greenwold Antler | Forest beast | Fellaxe / hunting identity |
| Gravekeeper's Tooth | Grave enemies | Crypt / Grave bead synergy |
| Tallow Drake Scale | Ash Drake Whelp | Heat / Hearthcraft / early drake flex |
| Blueglass Eye | Later watcher enemy | Precision / hidden object detection |
| Carmine Mask | Duelist humanoid | PvP / duel identity |

## Design Rules

1. Trophies are narrow and cultural.
2. Trophies should not be universally best.
3. Trophy source should be obvious from the item name.
4. Contract trophies can use assignment-only proof drops.
5. Trophy effects must respect the accessory trophy rules.
