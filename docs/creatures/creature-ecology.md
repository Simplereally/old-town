# Creature Ecology

Creatures make districts feel alive and dangerous. Safe civic spaces should stay safe; edge spaces carry risk.

| District | Creatures |
|----------|-----------|
| Sootcellar | Cellar Rat, Soot Rat, Blacksealed Cutpurse, Cellar King |
| Market Bell | No hostile spawns, event pests only |
| Foundry Row | Ash Drake Whelp rare, soot pests |
| Lath Yard | Road Crow, Bell Bat nearby |
| Patch Lane | Bog Fox, Stray Dog |
| Chalkhouse Court | Grave Wisp event, bead misfires |
| Warden Steps | Contract turn-ins, no hostile spawns |
| Shrine Hearth | Grave Wisp edge, cleansing NPCs |
| River Stoop | River Snapper, dock rats |
| Oldroad Gate | Stray Dog, Road Crow, Mud Goblin |
| Gravegate | Grave Mite, Grave Wisp |
| North Quarry Road | Mud Goblin, Mudhook Grib |

## Design Rules

1. The Market Bell and Warden Steps are safe by default.
2. Sootcellar teaches risk below safety.
3. Gravegate is the first visible danger escalation.
4. Creature placement should reinforce the district's skill loops.
