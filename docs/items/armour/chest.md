# Chest Armour

> All chest armour in Old Town: Harness (plate), Hauberk (chain), and Platecoat (heavy plate). 13 tiers each.

## Platecoat (Heavy Plate)

> Full plate torso. Maximum defence, heavy. Slight movement penalty.

- **Slot:** Chest
- **Weight:** Heavy
- **Defence bonus:** High
- **Magic bonus:** -10 (heavy plate blocks magic)
- **Movement penalty:** -5% run energy regeneration
- **Best for:** Maximum defence, tanking, heavy combat

## Chest Armour Comparison

| Feature | Harness | Hauberk | Platecoat |
|---------|---------|---------|-----------|
| **Defence** | Medium | Low-Medium | High |
| **Weight** | Medium | Light | Heavy |
| **Magic bonus** | None | +5 | -10 |
| **Movement** | None | None | -5% run |
| **Best for** | All-around | Hybrid/magic | Tanking |
| **Cost** | Cheap | Medium | Expensive |

## Design Rules

1. **Harness is the standard.** Breastplate, no special bonuses or penalties.
2. **Hauberk is the hybrid.** Lighter, magic bonus, less defence.
3. **Platecoat is the tank.** Heavy, maximum defence, magic penalty, run penalty.
4. **Cobbled is the joke.** Wood planks, chain mail of prayers, pot lids.
5. **Starfall is the mythic.** Meteor plate, meteor chain, meteor full plate.
