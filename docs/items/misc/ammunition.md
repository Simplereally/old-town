# Ammunition

> All ammunition in Old Town. Used by ranged weapons. Ammunition follows the ranged tier system: bows use organic tier names, crossbows and heavy heads use metal tier names.

## Ammo Types Overview

| Ammo Type | Used By | Tier Naming | Example |
|-----------|---------|-------------|---------|
| **Arrows** | Bows (all) | Organic (bow tier) | Lathwood Arrows, Blackstring Arrows |
| **War Arrows** | Heavy bows (Warbow, Longbow) | Metal (head tier) | Graveiron War Arrows |
| **True Arrows** | Precision bows (Stillbow, Recurve) | Organic (bow tier) | Argentwood True Arrows |
| **Bolts** | Light crossbows (Latchbow) | Metal (head tier) | Pig Iron Bolts |
| **Quarrels** | Standard/heavy crossbows (Crossbow, Arbalest) | Metal (head tier) | Bellmetal Quarrels |
| **Barbs** | Fast bows (Quickbow, Shortbow) | Organic (bow tier) | Greenwold Barbs |
| **Bodkins** | Armour-piercing | Metal (head tier) | Wardensteel Bodkins |
| **Broadheads** | High-damage | Metal (head tier) | Carmine Steel Broadheads |
| **Starheads** | Mythic | Metal (head tier) | Starfall Starheads |

## Design Rules

1. **Ammo follows the head material.** Arrowheads and bolt-heads use metal tier names. Bow-tier arrows (Lathwood Arrows, Greenwold Barbs) use bow-tier names.
2. **Never use "Bronze Arrow", "Iron Arrow", "Steel Arrow".** Use tier names: Pennywrought Bolt, Wardensteel Bodkin, Starfall Starhead.
3. **Bodkins are the first serious unlock.** Historically real, sharp, memorable.
4. **Starheads are endgame only.** Meteor-metal, mythic, rare.
5. **Ammo is stackable.** All ammo types stack up to 1000 per slot.
6. **Ammo is consumed per shot.** Each ranged attack uses one ammo.
7. **Ammo bonuses add to weapon stats.** Ranged Strength from ammo adds to weapon Ranged Strength.
