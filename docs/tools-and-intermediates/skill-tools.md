## Content Notes

- Item IDs should use kebab-case and follow item conventions, for example `chalk_compass` and `warden_contract_book`.
- Starter tools should be available through early shops, tutorial rewards, or simple crafting.
- Midgame tools should require at least one inter-skill dependency.
- Endgame tools should require a high-tier resource, station, or mastery path.
