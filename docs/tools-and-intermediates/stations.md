# Stations

Stations are how towns matter. Advanced work should require a place in the world, not only the right inventory stack.

## Station Canon

| Station | Skill | Role |
|---------|-------|------|
| Anvil | Smithing | Forge gear |
| Bellows Furnace | Smithing / Hearthcraft | Smelt bars |
| Bow Bench | Bowcraft | String bows and crossbows |
| Tanning Frame | Tailoring | Cure hides |
| Dye Vat | Tailoring / Gardening | Colour cloth |
| Bead Kiln | Beadwork / Hearthcraft | Fire beads |
| Bead Loom | Beadwork | Make bead strings |
| Apothecary Bench | Apothecary | Mix potions |
| Kitchen Range | Cooking / Hearthcraft | Advanced cooking |
| Carpenter's Bench | Carpentry | Build furniture and stations |
| Map Table | Cartography | Assemble surveys |
| Warden Board | Wardenry | Claim and turn in contracts |
| Shrine Hearth | Favour / Hearthcraft | Offerings and blessings |

## Design Rules

1. Starter recipes may work from inventory or simple public stations.
2. Advanced recipes should require named stations.
3. Stations are objects in content, not hardcoded coordinates.
4. The server validates station proximity and recipe eligibility.
5. Stations may gate recipe families, processing speed, batch size, or quality.
6. Town layouts should cluster stations into believable workshops.
