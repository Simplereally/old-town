# Skill Outfits

Skill outfits are identity gear. They should make professions visible and memorable without becoming mandatory combat equipment.

## Item Families

| Family | Role |
|--------|------|
| Skill outfits | Visual profession sets with small utility bonuses |
| Mastery keepsakes | High-skill proof items |
| Guild badges | Access or reputation markers |
| Profession capes | Cape-slot identity rewards |
| Tool ornaments | Cosmetic or minor utility upgrades |
| Non-combat rings | Utility bonuses for skilling loops |
| Non-combat charms | Luck, yield, or access helpers |
| Work belts | Preparation and carrying bonuses |
| Skilling trophies | Long-term achievement markers |
| Task reward cosmetics | Wardenry, Sleight, and guild rewards |

## Design Rules

1. Outfits should identify a profession before they optimize it.
2. Utility bonuses should be narrow, readable, and content-driven.
3. Outfits must not obsolete normal armour in combat.
4. Mastery items should be memorable names, not generic "skill cape" copies.
5. Guild badges and profession capes may be untradeable if they represent progress.
6. Reclaim behavior must be explicit for untradeable identity items.
