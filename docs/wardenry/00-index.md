# Wardenry Index

Old Town's Wardenry system is the town making combat useful. Wardenry is the OSRS-style Slayer-equivalent: Wardens assign Contracts, players complete them for Warden Marks, and the Warden Locker holds rewards.

## Design rules

1. Wardenry is not "kill random monsters." It is the town making combat useful.
2. Every contract must answer: who assigned it, what target, where, how many kills/proofs, danger level, helpful skills/items, boosted drops, completion reward, mark unlocks, repeat value.
3. Free-killing remains valid. Contracts improve structure and rewards.
4. No daily lock, no streak FOMO, no faction reputation, no battle pass.
5. Marks buy utility, unlocks, blocks, and cosmetics, not universal power.
6. Wardenry should guide combat, not replace exploration.
7. Boss Warrants are opt-in or uncommon.
8. Notorious Variants are bonuses, not obligations.

| "Chain 10." | Contract Chain milestone of 10. |
| "Got a posted grave task." | Posted Contract in Lowgrave. |

| "Widen bats." | Extended a Bell Bat contract. |
| "Named warrant: Mudhook." | Boss task for Mudhook Grib. |
| "Notorious rat spawned." | A Ledger-Gnaw Rat appeared. |
| "Need Warden marks for locker." | Saving marks for a Warden Locker reward. |
