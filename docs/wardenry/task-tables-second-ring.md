## Second-Ring Task Rules

1. Second-ring tasks are seeded, not fully defined.
2. Second-ring tasks require area route and high combat level.
3. Second-ring tasks are dangerous.
4. Second-ring tasks give high marks.
5. Second-ring boss tasks are rare and rewarding.
6. Full encounter design belongs in the second-ring implementation layer.

## Deferred to Implementation
