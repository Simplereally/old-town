# Starter Shop Stocks

All prices are provisional tuning values.

## Counting House

Owner: Tomas Tally.

Role: bank, reclaim, item audit, storage.

The Counting House does not sell combat power. All services are governed by [`banks-storage-and-reclaim.md`](banks-storage-and-reclaim.md).

| Service | Fee | Notes |
|---------|----:|-------|
| Basic bank access | Free | Always available |
| Quest item reclaim | 0–50 coins | Free for mandatory quest blockers |
| Death reclaim | % of item value | Later, capped early |
| Container storage | Fee per container | Later sink |
| Coin exchange | Tiny fee | Converts odd currencies later |
| Lost tool audit | 10 coins | Starter convenience |

Rules:

- Reclaim fees are sinks, not punishment spirals.
- Quest blockers must be recoverable.
