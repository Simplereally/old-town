# Banks, Storage, and Reclaim

The Counting House is the starter bank and reclaim authority.

NPC: Tomas Tally.

## Services

| Service | Fee | Notes |
|---------|----:|-------|
| Basic bank access | 0 | Always available |
| Quest item reclaim | 0-50 coins | Free for mandatory quest blockers |
| Death reclaim | % of item value | Later, capped early |
| Container storage | Fee per container | Later sink |
| Coin exchange | Tiny fee | Converts odd currencies later |
| Lost tool audit | 10 coins | Starter convenience |

## Rules

1. The bank never sells combat power.
2. Reclaim fees are sinks, not punishment spirals.
3. Quest blockers must be recoverable.
4. Tomas Tally is the first reclaim voice.
