# Currency and Value Bands

Keep early currency simple. Coins come first; Bell Tokens and Warden Marks add civic and contract identity.

## Currency

| Currency | Role |
|----------|------|
| Coins | Universal trade currency |
| Bell Tokens | Civic, Favour, and Warden reward currency |
| Warden Marks | Contract progression, not general currency |
| Guild Chits | Later skill guild currency |
| Festival Scrip | Later event currency |

## Value Bands

| Band | Coin Range | Use |
|------|-----------:|-----|
| Junk | 1-3 | Rat tails, torn cloth, failed scraps |
| Common | 4-15 | Food, basic resources, feathers |
| Useful starter | 16-60 | Tools, starter weapons, basic consumables |
| Early gear | 61-250 | Full starter pieces, pouches, rings |
| Midgame | 251-2,000 | Wardensteel/Greenwold-level items |
| Rare | 2,001-20,000 | Trophies, rare recipes, high-tier components |
| Prestige | 20,000+ | Crown/Starfall, cosmetics, rare services |
