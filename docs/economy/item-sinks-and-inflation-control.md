# Item Sinks and Inflation Control

Early sinks should be gentle and constant. The player should feel poor, not punished.

## Early Sinks

| Sink | Role |
|------|------|
| Repair fees | Keeps tools and gear physical |
| Station fees | Public furnace, kiln, tanning, cooking |
| Tanning fees | Turns hides into useful materials |
| Bead firing fees | Makes bead volume cost something |
| Shrine candles | Recurring Favour demand |
| Contract deposits | Later Wardenry sink |
| Ferry fares | Route convenience sink |
| Map copying | Cartography sink |
| Reclaim fees | Recovery sink |
| Shop convenience premium | Prevents shop skipping |

## Design Rules

1. Avoid punitive sinks in the first hour.
2. Use small repeated fees before large surprise fees.
3. Shops should pay less than player trade value.
4. Services should often save time, not replace skills.
