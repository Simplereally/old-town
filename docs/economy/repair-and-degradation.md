# Repair and Degradation

Repair is a gentle recurring sink. It should make tools feel physical without punishing new players.

## Repair Rules

| Item Type | Starter Rule |
|-----------|--------------|
| Starter tools | Cheap repair, 5-20 coins |
| Early gear | 5-10% item value |
| Containers | Flat repair fee by tier |
| Quest blockers | Free or near-free reclaim |
| High-tier gear | Later scaling sink |

## Design Rules

1. Degradation should not break first-hour play.
2. Repair costs scale with item value and severity.
3. NPC repair identity matters: Osric repairs forge tools, Nell repairs ranged armour, Mother Tallow repairs bead pouches.
4. Repair should never be cheaper than ignoring production forever.
