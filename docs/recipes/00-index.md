## Core Rule

Every recipe must answer:

| Field | Meaning |
|-------|---------|
| Recipe ID | Stable kebab-case content ID |
| Skill | Skill that gains XP |
| Level | Required skill level |
| XP | Provisional XP reward |
| Action ticks | Tick cost |
| Tool | Required carried or equipped tool |
| Station | Optional or required world object |
| Inputs | Consumed items |
| Outputs | Produced items |
| Failure | Burn, waste, partial refund, or no failure |
| Byproduct | Ash, scraps, offcuts, slag, empty phial |
| Unlock source | Default, quest, guild, shop, drop, Wardenry contract |
| Economy role | Training, profit, utility, PvP, PvE, prestige |
