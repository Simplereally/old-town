# Audio assets (E47)

Original generated placeholder tones for Old Town. These are simple sine-wave
OGG files produced for development — **not** OSRS/Jagex assets.

Replace with hand-authored loops and one-shots as art production catches up.
Content definitions in `content/audio/` reference paths under this directory.
At runtime the client loads mirrored copies from `/audio/...` (Vite `public/`).
