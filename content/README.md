# Content

JSON content definitions for Old Town — items, NPCs, objects, skills, spells, quests,
dialogue, drop tables, and region maps. Every file is validated against the shared
content schemas (`packages/shared/src/content-schemas`) by the content validator CLI
(`tools/content-validator`).

Subfolders and seed data are populated in E02. Do not hand-author region maps — use the
world editor (E14).
